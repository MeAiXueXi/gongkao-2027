## 按省份看

江苏、山东、浙江、广东、安徽、贵州、陕西、上海，各省命题风格差别不小。
复习优先级是：本省近五年真题 → 国考和联考里题型相同的部分 → 其他省份。
不是一路的卷子，做十套不如吃透一套。

## 真题怎么用

一套卷子至少用三遍。第一遍掐时间完整做，暴露真实水平；第二遍不看答案，
回材料逐段标功能、对采分点，看答案是怎么把材料原句压成要点词的；第三遍
隔一周重写，和第一遍对比，看你重复掉进去的坑是哪一个。

只做一遍对完答案就翻篇，真题就只剩模拟考一个功能，最值钱的部分被扔掉了。
